# Digital Incident Reporting System - Frontend

Vanilla HTML5, CSS3, and JavaScript frontend for the Digital Reporting System.

## Features
- **Zero-Knowledge Privacy:** Client-side WebCrypto AES-GCM-256 encryption.
- **Interactive Voice Dictation Studio:** Speech-to-text with multi-language support (English, Hindi, Telugu), 1-click templates, and Windows `Win + H` integration.
- **Themed Multi-Language Engine:** Complete dynamic translations for English, Hindi, and Telugu.
- **Integrated Backend:** Automatically connects to the live Render backend (`https://digital-reporting-system-8xtk.onrender.com`).
